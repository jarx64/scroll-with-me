# Change Log

All notable changes to Scroll With Me are documented here.

## [Unreleased]

### Added

- Caret following for viewport-only vertical scrolling.
- Independent state for normal, split, read-only, virtual, and text diff editors.
- Multiple-caret support with preferred-column restoration and document-boundary clamping.
- Automatic suspension while a non-empty selection is present.
- The `scrollWithMe.enabled` user/workspace setting.
- Unit and extension-host tests plus user and maintainer documentation.
